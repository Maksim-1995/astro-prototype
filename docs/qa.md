# Проверка первого экрана и перехода: версия 2

Проверено в установленном Firefox в headless-режиме через встроенный Marionette. Для узких экранов использован iframe с точным viewport: минимальная ширина окна настольного Firefox составляет 500 px.

- 1440 × 914: изображение загрузилось, горизонтальной прокрутки нет.
- Клик по сигналу меняет текст и `aria-pressed`.
- Диалог открывается и закрывается.
- Проверены промежуточные положения перехода на 35%, 60% и 90% прокрутки: слои движутся, первая композиция уходит, чат появляется. Обратная прокрутка возвращает первую сцену и её доступность для клавиатуры.
- При прокрутке показывается сцена приватности, скрытая сцена исключена из фокуса.
- Демонстрация сообщения скрывает его; повторное нажатие восстанавливает.
- 390 × 844: горизонтальной прокрутки нет, меню открывается и закрывается; кнопка демонстрации сообщения выше нижнего индикатора, пересечения нет.
- 360 × 640: обе сцены переходят в обычный поток и доступны для взаимодействия, горизонтальной прокрутки нет.
- 760 × 700 и 650 × 800: заголовок не пересекается с описанием, весь блок управления сообщением расположен выше нижнего индикатора. Добавлены соответствующие браузерные assertions.
- `node --check dist/app.js`: успешно.
- Проверены локальные ссылки на assets, уникальность HTML id и `git diff --check`.
- Отдельный слой героини имеет настоящий alpha-канал; исходное изображение сохранено.

Режим `prefers-reduced-motion` проверен по коду; отдельная проверка системной настройки в браузере не проводилась. Физические телефоны, Safari и Chromium в этом окружении не проверены.

Браузерная smoke-проверка: `docs/browser_qa.py`. Для неё требуется отдельный запущенный Firefox с `--marionette` и портом 2828. Она не отправляет данные во внешние API.
