# AstroSynchro: первый интерактивный прототип

Первый экран и переход к демонстрации приватности по предоставленному ТЗ. Название, тексты и материалы временные. Регистрации, API и сбора контактов нет.

## Запуск

Из каталога `astro-prototype`:

```bash
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`.

## Что проверить

- При прокрутке героиня и орбиты смещаются, первая сцена переходит в сцену приватности.
- Звёздный сигнал и плавающая карточка реагируют на наведение/нажатие; на компьютере доступна навигация клавиатурой.
- В сцене приватности сообщение можно отпустить и вернуть повторным нажатием.
- Кнопки приглашения открывают описание прототипа, без формы и передачи данных.
- Узкий экран, открытие меню и режим уменьшения движения в системе.

## Материалы

Палитра взята из скриншотов ТЗ: `#0A051C`, `#EFEFF1`, `#6941B4`, `#B8B5FF`. Логотип представлен временной текстовой надписью.

Героиня создана встроенным image_gen. Файл: `dist/assets/hero-woman.png`. Точный запрос сохранён в [docs/hero-prompt.md](docs/hero-prompt.md).

## Проверки

```bash
node --check dist/app.js
```

Для полноценной приёмки нужны проверка в браузерах на ПК/телефоне и согласование художественного направления. Прототип демонстрирует движение слоёв; изображение героини не является покадровой видеоанимацией.
