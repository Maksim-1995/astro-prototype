# AstroSynchro: первый экран и законченный переход

Обновлённый первый экран и переход к демонстрации приватности по предоставленному ТЗ. Героиня, фон, орбиты, типографика и передний свет разделены на слои. Название и тексты временные. Регистрации, API и сбора контактов нет.

## Запуск

Из каталога `astro-prototype`:

```bash
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`.

## Что проверить

- При прокрутке композиция приближается, заголовок уходит, световой контур раскрывается, появляется приватный чат. Переход работает в обе стороны.
- Звёздный сигнал и плавающая карточка реагируют на наведение/нажатие; на компьютере доступна навигация клавиатурой.
- В сцене приватности сообщение можно отпустить и вернуть повторным нажатием.
- Кнопки приглашения открывают описание прототипа, без формы и передачи данных.
- Узкий экран, открытие меню и режим уменьшения движения в системе.

## Проверки

```bash
node --check dist/app.js
```

Результаты браузерной проверки: [docs/qa.md](docs/qa.md). Для окончательной приёмки нужны реальные телефоны и согласование художественного направления. Прототип демонстрирует движение отдельных слоёв; изображение героини не является покадровой видеоанимацией.
