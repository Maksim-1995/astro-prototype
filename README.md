# AstroSynchro

Адаптивный визуальный прототип промосайта приложения знакомств и отдельный Django backend для заявок на бета-тест. Первый экран и переход к приватному чату уже реализованы. Героиня, фон, орбиты, типографика и передний свет разделены на слои. Название и тексты временные; остальные разделы полного ТЗ ещё предстоит подготовить.

Backend сохраняет email и согласие с редакцией политики, предоставляет Django Admin и проверку доступности БД. Это список ожидания, не регистрация аккаунта приложения. JWT, реальный чат и расчёт совместимости в этот этап не входят. Приём контактов по умолчанию выключен до появления реального документа о приватности.

## Только визуальный прототип

Из каталога `astro-prototype`:

```bash
python3 -m http.server 8000 --directory dist
```

Открыть `http://localhost:8000`. Исходный `dist/config.js` не содержит адреса API и ссылки на политику, поэтому статический preview не отправляет персональные данные. То же относится к опубликованной статической версии Sites без отдельного подключения backend.

## Frontend и backend в Docker

```bash
cp .env.example .env
python3 -c 'import secrets; print(secrets.token_urlsafe(64))'
python3 -c 'import secrets; print(secrets.token_urlsafe(32))'
```

Запишите первую строку в `DJANGO_SECRET_KEY`, вторую — в `DB_PASSWORD` файла `.env`.

```bash
docker compose up --build -d
curl --fail http://localhost:8080/api/v1/health/
docker compose exec backend python manage.py createsuperuser
```

Сайт — `http://localhost:8080/`, админка — `http://localhost:8080/admin/`. Nginx отдаёт frontend и статику Django, API проксирует к Gunicorn. PostgreSQL 18 хранит данные в отдельном томе. Backend и БД доступны только внутри Docker-сети. Миграции и `collectstatic` выполняются одноразовым сервисом до запуска web.

Подробные настройки, включение формы после согласования политики, пример POST, локальный запуск через uv и подготовка хостинга: [docs/backend.md](docs/backend.md).

## Что проверить

- При прокрутке композиция приближается, заголовок уходит, световой контур раскрывается, появляется приватный чат. Переход работает в обе стороны.
- Звёздный сигнал и плавающая карточка реагируют на наведение/нажатие; на компьютере доступна навигация клавиатурой.
- В сцене приватности сообщение можно отпустить и вернуть повторным нажатием.
- Кнопки приглашения открывают диалог бета-теста; без настроенного API и реальной политики отправка контактов недоступна.
- Узкий экран, открытие меню и режим уменьшения движения в системе.
